# Read Before Write

When the user asks a question, default to answering it WITHOUT editing any files.

Only edit files when the user explicitly requests it — phrases like:
- "update my files", "log this", "write this down", "document this"
- "add this to my protocol", "save this"

Questions like "What does X mean?", "Is Y safe?", "Research Z" are informational.
Do not modify patient files in response to informational questions.
