# Monitoring (patient_file/4_monitoring/)

This folder tracks whether interventions are working.

## When to create/update monitoring entries
- When a new protocol is started (baseline tracking)
- When the patient reports symptoms or progress
- When new lab results arrive that relate to an active intervention

## Format
- Use clear dates (YYYY-MM-DD)
- Link back to the relevant intervention in `3_interventions/`
- Track both objective measures (lab values) and subjective symptoms
